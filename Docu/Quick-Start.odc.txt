
QUICK START - Cuda subsystem

CUDA Runtime API bindings (cuda_runtime.h, CUDA 12) for BlackBox amd64 Linux.
Mechanism: library attribute in the module header + [ccall] declarations
(like LinDl/LinLibc). The BB loader itself does dlopen("libcudart.so.12").

Requirements: NVIDIA driver + libcudart.so.12 in the system (CUDA Toolkit 12).
Without the library the CudaRt module will not load (the rest of the system
is not affected).

Modules:
  CudaRt   - raw [ccall] bindings (pure interface module, no bodies).
  CudaUtil - CP wrappers: ErrorText, DeviceName.
  CudaTest - smoke test: versions, devices, H2D/D2H memory round-trip.

Run the test (console):
  echo 'CudaTest.Go' | ./run-bb64 --console

Expected output (example):
  cuda runtime=12.0 driver=13.0
  devices=2
  dev0: NVIDIA GeForce RTX 5070 Ti
  mem free=13435MB total=15817MB
  CudaTest OK

Notes:
  - the data address of a dynamic array = SYSTEM.ADR(a[0]), not VAL(LONGINT, a);
  - C string parameters are VAR ARRAY [untagged] OF SHORTCHAR;
  - string terminator for SHORTCHAR is 0X.
